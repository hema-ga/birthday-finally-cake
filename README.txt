BIRTHDAY CAKE — GITHUB PAGES UPLOAD

FILES
- index.html — the complete website, cake design, candle animation, microphone blow detection, song logic and photo gallery.
- birthday-song.mp3 — the birthday song used after the surprise starts.
- photo1.jpg ... photo5.jpg — the five birthday photos supplied for the website.

HOW TO USE
1. Unzip this folder.
2. Upload ALL 7 files to the ROOT of the birthday-cake GitHub repository.
3. In GitHub: Settings -> Pages -> Deploy from branch -> main -> /(root) -> Save.
4. Open the generated HTTPS GitHub Pages link on the birthday laptop.
5. Click “Start birthday surprise” once. This is required by normal browser security to unlock the microphone/audio.
6. Allow microphone access. The site calibrates for about one second, starts the song, and waits for a sustained blow.
7. Blow toward the laptop microphone. The candles extinguish one by one, the song stops, and the photo/message screen appears.

IMPORTANT
- Microphone access needs HTTPS, so test the GitHub Pages URL rather than a local file.
- Browsers generally do not allow audible audio to autoplay before the visitor interacts with the page. The first button click is therefore intentional.
- If a very quiet blow does not trigger, blow a little more directly toward the laptop microphone.
